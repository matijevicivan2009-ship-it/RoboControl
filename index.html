02

Kako 3D simulator radi?

Model povezuje kutove zglobova s položajem hvataljke u prostoru.

⚙️ Zglobovi

Baza rotira cijelu ruku, dok rame i lakat mijenjaju položaj članaka. Klizači odmah mijenjaju 3D model.

📐 3D kinematika

Iz kutova i duljina članaka računa se položaj završne točke robota u koordinatnom sustavu X, Y i Z.

🦾 Hvataljka

Klizač mijenja razmak prstiju hvataljke i simulira prihvat predmeta.

Pojednostavljene formule

r = L₁ cos(θ₁) + L₂ cos(θ₁ + θ₂)

X = r sin(θ₀)   •   Z = r cos(θ₀)

Y = H + L₁ sin(θ₁) + L₂ sin(θ₁ + θ₂)

03

O projektu

Web-aplikacija izrađena kao demonstracijski dio završnog rada.

RoboControl 2.0 prikazuje princip upravljanja robotskom rukom bez fizičkog robota. Korisnik upravlja zglobovima, hvataljkom, prati X/Y/Z koordinate, sprema položaje i pokreće demo.

Projekt koristi HTML, CSS, JavaScript i Three.js i pripremljen je za GitHub Pages.
